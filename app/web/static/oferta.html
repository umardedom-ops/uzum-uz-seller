Ommaviy oferta

Uzum Market sotuvchilari uchun axborot-tahliliy xizmat ko'rsatish to'g'risida
Tahrir sanasi: [SANA] · Kuchga kirish sanasi: e'lon qilingan kundan

Diqqat. Ushbu hujjat — ommaviy oferta. Xizmatdan foydalanishni boshlash (Telegram-botda «Qabul qilaman» tugmasini bosish) ofertani to'liq va so'zsiz qabul qilish (aksept) hisoblanadi. Iltimos, matnni oxirigacha o'qing.

1. Umumiy qoidalar

  1. Ushbu hujjat [TASHKILOT TO'LIQ NOMI] (keyingi o'rinlarda — Ijrochi) tomonidan har qanday jismoniy yoki yuridik shaxsga (keyingi o'rinlarda — Foydalanuvchi) bildirilgan rasmiy taklif — ommaviy ofertadir.
  2. Oferta O'zbekiston Respublikasi Fuqarolik kodeksining oferta, ommaviy oferta va aksept to'g'risidagi qoidalari asosida tuzilgan.
  3. Foydalanuvchi ofertani qabul qilgan paytdan boshlab Tomonlar o'rtasida yozma shaklda tuzilgan shartnomaga teng kuchga ega bitim vujudga keladi.
  4. Ijrochi ofertaga bir tomonlama o'zgartirish kiritish huquqiga ega. O'zgartirishlar ushbu sahifada e'lon qilingan kundan kuchga kiradi. Foydalanuvchi xizmatdan foydalanishni davom ettirishi o'zgartirishlarga rozilik hisoblanadi.

2. Asosiy tushunchalar

Xizmat
Telegram-bot ([BOT USERNAME]) orqali ko'rsatiladigan axborot-tahliliy xizmat: Foydalanuvchining Uzum Market'dagi do'koni bo'yicha ma'lumotlarni yig'ish, tahlil qilish va hisobotlar shakllantirish.
API kalit
Uzum Market sotuvchi kabinetida Foydalanuvchi tomonidan yaratiladigan va Ijrochiga ixtiyoriy ravishda taqdim etiladigan kirish kaliti.
Hisobot
Xizmat tomonidan avtomatik shakllantiriladigan tahliliy hujjat (Excel, PDF, da'vo xati loyihasi va boshqalar).
Obuna
Tanlangan tarif bo'yicha muayyan muddatga Xizmatdan foydalanish huquqi.

3. Oferta predmeti

  1. Ijrochi Foydalanuvchiga axborot-tahliliy xizmat ko'rsatadi, Foydalanuvchi esa tanlangan tarifga muvofiq haq to'laydi.
  2. Xizmat quyidagilarni o'z ichiga oladi:
    • do'kon ma'lumotlarini muntazam yig'ish va saqlash;
    • ombor qoldiqlari, sotuvlar, qaytarishlar, komissiya va logistika bo'yicha tahliliy hisob-kitoblar;
    • aniqlangan nomuvofiqliklar bo'yicha hisobotlar va hujjat loyihalarini shakllantirish;
    • Telegram orqali xabarnomalar yuborish.
  3. Xizmat masofadan, Telegram-bot interfeysi orqali ko'rsatiladi.

4. Ijrochining Uzum Market bilan aloqasi yo'qligi

Ijrochi «Uzum Market» MChJ bilan hech qanday huquqiy aloqada emas, uning vakili, agenti, hamkori yoki filiali hisoblanmaydi. Xizmat mustaqil ravishda ko'rsatiladi va Uzum Market tomonidan tasdiqlanmagan yoki homiylik qilinmagan.
  1. Xizmat Uzum Market tomonidan taqdim etilgan rasmiy API interfeysidan foydalanadi.
  2. Uzum Market tomonidan API ishlashini to'xtatish, o'zgartirish yoki cheklash Xizmat ishlashiga ta'sir qilishi mumkin. Bunday holatlar Ijrochining aybi hisoblanmaydi.

5. Aksept tartibi

  1. Aksept quyidagi harakatlar orqali amalga oshiriladi:
    1. Telegram-botda ushbu oferta bilan tanishish;
    2. «Qabul qilaman» tugmasini bosish.
  2. Aksept qilingan sana va vaqt Ijrochining axborot tizimida qayd etiladi va nizo yuzaga kelganda dalil hisoblanadi.
  3. Ofertani qisman qabul qilishga yo'l qo'yilmaydi.

6. Sinov muddati, tariflar va to'lov

  1. Yangi Foydalanuvchiga 3 (uch) kunlik bepul sinov muddati beriladi. Sinov muddatida Xizmatning barcha imkoniyatlari ochiq bo'ladi.
  2. Amaldagi tariflar:
    TarifNarx (oyiga)Hajmi
    Basic149 000 so'mAsosiy tahlil va hisobotlar
    Pro299 000 so'mBarcha imkoniyatlar
  3. Narxlar O'zbekiston Respublikasi milliy valyutasida ko'rsatilgan. Ijrochi narxlarni o'zgartirish huquqiga ega; o'zgargan narx allaqachon to'langan davrga nisbatan qo'llanilmaydi.
  4. To'lov Xizmatga to'lov tizimlari orqali oldindan amalga oshiriladi. Obuna to'lov tasdiqlangan paytdan boshlab faollashadi.
  5. Obuna muddati tugaganda Xizmatdan foydalanish avtomatik cheklanadi. Yig'ilgan ma'lumotlar 8-bo'limda ko'rsatilgan muddat davomida saqlanadi.
  6. Ijrochi tomonidan Xizmat texnik sabablarga ko'ra ketma-ket [N] kundan ortiq ko'rsatilmagan bo'lsa, Foydalanuvchining murojaatiga binoan obuna muddati shu muddatga uzaytiriladi.

6.1. Pulni qaytarish

  1. To'langan mablag' quyidagi hollarda qaytariladi:
    • Ijrochining aybi bilan Xizmat ko'rsatilmagan bo'lsa;
    • to'lov texnik xato tufayli ikki marta amalga oshirilgan bo'lsa.
  2. Xizmat ko'rsatilgan, biroq Foydalanuvchi natijadan qoniqmagan hollarda (jumladan, tahlil natijasida nomuvofiqlik aniqlanmasa) to'langan mablag' qaytarilmaydi. Sinov muddati aynan shu maqsadda beriladi.
  3. Qaytarish murojaati [SUPPORT KANALI] orqali yuboriladi va [N] ish kuni ichida ko'rib chiqiladi.

7. API kalit va do'kon ma'lumotlari

  1. Foydalanuvchi API kalitni ixtiyoriy ravishda taqdim etadi va uni Uzum Market kabinetida istalgan vaqtda bekor qilish huquqiga ega.
  2. Ijrochi API kalitni shifrlangan holda saqlaydi va uni uchinchi shaxslarga oshkor qilmaydi.
  3. Ijrochi Foydalanuvchining do'koniga faqat o'qish uchun murojaat qiladi. Tovarlar, narxlar, qoldiqlar, buyurtmalar va boshqa ma'lumotlarga o'zgartirish kiritilmaydi.
  4. Foydalanuvchi API kalitni taqdim etish orqali Ijrochiga do'kon ma'lumotlarini Xizmat ko'rsatish maqsadida qayta ishlashga rozilik beradi.
  5. Foydalanuvchi API kalitni bekor qilgan taqdirda Xizmat ko'rsatish to'xtatiladi; bu holda to'langan mablag' qaytarilmaydi.

8. Shaxsiy ma'lumotlar

  1. Ijrochi quyidagi ma'lumotlarni qayta ishlaydi: Telegram identifikatori, ism, foydalanuvchi nomi, telefon raqami, do'kon ma'lumotlari.
  2. Qayta ishlash maqsadi — Xizmat ko'rsatish, Foydalanuvchi bilan bog'lanish va to'lovlarni hisobga olish.
  3. Ma'lumotlar O'zbekiston Respublikasining shaxsiy ma'lumotlar to'g'risidagi qonunchiligiga muvofiq qayta ishlanadi va saqlanadi.
  4. Ma'lumotlar uchinchi shaxslarga uzatilmaydi, qonunda nazarda tutilgan hollar bundan mustasno.
  5. Foydalanuvchi [SUPPORT KANALI] orqali murojaat qilib, o'z ma'lumotlarini o'chirishni talab qilishi mumkin. Ma'lumotlar [N] kun ichida o'chiriladi.
  6. Obuna tugagandan so'ng ma'lumotlar [N] oy davomida saqlanadi, so'ngra o'chiriladi.

9. Hisobotlarning maqomi va javobgarlik chegaralari

Xizmat tomonidan shakllantirilgan hisobotlar — tahliliy taxminlar bo'lib, aniqlangan holatning yuridik jihatdan tasdiqlangan dalili hisoblanmaydi. Har qanday da'voni Uzum Market'ga taqdim etishdan oldin Foydalanuvchi ma'lumotlarni mustaqil tekshirishi shart.
  1. Hisobotlar Uzum Market API'sidan olingan ma'lumotlar asosida avtomatik tarzda shakllantiriladi. Manba ma'lumotlaridagi noaniqlik hisobot natijasiga ta'sir qilishi mumkin.
  2. Da'vo xati loyihasi — namunaviy hujjat bo'lib, uni yuborish yoki yubormaslik to'g'risidagi qaror va uning oqibatlari uchun javobgarlik butunlay Foydalanuvchi zimmasida.
  3. Ijrochi quyidagilar uchun javobgar emas:
    • Foydalanuvchi tomonidan hisobot asosida qabul qilingan qarorlar oqibatlari;
    • Uzum Market bilan yuzaga keladigan nizolar natijasi;
    • boy berilgan foyda, bilvosita zarar va obro'ga yetkazilgan zarar;
    • Uzum Market API'sining ishlamasligi yoki ma'lumot bermasligi;
    • Telegram xizmatining ishlamay qolishi.
  4. Ijrochining har qanday holatdagi umumiy javobgarligi Foydalanuvchi tomonidan oxirgi obuna davri uchun to'langan summa bilan cheklanadi.

10. Kafolatlar

  1. Ijrochi hech qanday moliyaviy natijani kafolatlamaydi: jumladan, nomuvofiqliklar albatta topilishini, topilgan summa Uzum Market tomonidan qoplanishini yoki Foydalanuvchi daromadining oshishini.
  2. Xizmat «boricha» (as is) asosida ko'rsatiladi. Ijrochi Xizmatning uzluksiz va xatosiz ishlashini kafolatlamaydi.
  3. Ijrochi Xizmatni takomillashtirish, funksiyalarni qo'shish yoki olib tashlash huquqiga ega.

11. Tomonlarning huquq va majburiyatlari

11.1. Ijrochi majburiyatlari

  • Xizmatni tanlangan tarifga muvofiq ko'rsatish;
  • API kalit va shaxsiy ma'lumotlarni himoyalangan holda saqlash;
  • do'kon ma'lumotlariga faqat o'qish uchun murojaat qilish;
  • Foydalanuvchi murojaatlarini [N] ish kuni ichida ko'rib chiqish.

11.2. Foydalanuvchi majburiyatlari

  • haqiqiy ma'lumotlarni taqdim etish;
  • tanlangan tarif bo'yicha o'z vaqtida to'lash;
  • faqat o'ziga tegishli yoki qonuniy kirish huquqiga ega bo'lgan do'kon API kalitini taqdim etish;
  • hisobotlarni uchinchi shaxslarga tijorat maqsadida qayta sotmaslik;
  • Xizmat ishiga texnik aralashuvga urinmaslik.

12. Xizmatni to'xtatish

  1. Ijrochi Foydalanuvchi ushbu oferta shartlarini buzgan taqdirda Xizmat ko'rsatishni bir tomonlama to'xtatish huquqiga ega. Bu holda to'langan mablag' qaytarilmaydi.
  2. Foydalanuvchi istalgan vaqtda API kalitni bekor qilish yoki [SUPPORT KANALI] orqali murojaat qilish yo'li bilan Xizmatdan voz kechishi mumkin.

13. Nizolarni hal etish

  1. Tomonlar nizolarni muzokara yo'li bilan hal etishga harakat qiladilar.
  2. Da'vo tartibi majburiy: da'vo [N] kun ichida ko'rib chiqiladi.
  3. Kelishuvga erishilmagan taqdirda nizo O'zbekiston Respublikasi qonunchiligiga muvofiq sud tartibida hal etiladi.

14. Yakuniy qoidalar

  1. Ushbu ofertada tartibga solinmagan masalalar O'zbekiston Respublikasi qonunchiligi bilan tartibga solinadi.
  2. Oferta muddatsiz amal qiladi.
  3. Oferta bandlaridan biri haqiqiy emas deb topilsa, qolgan bandlar o'z kuchini saqlaydi.
